# JINHEXI 后台与亚马逊引导说明

## 当前网站定位

`jhicashmere.com` 作为品牌独立站，主要负责：

- 展示 JINHEXI 品牌形象
- 展示女装毛衣/羊绒针织产品
- 发布面料、洗护、穿搭、品牌文章
- 引导零售客户到 Amazon 下单
- 承接批发、外贸、合作询盘

前期不建议独立站直接收款，先用 Amazon 完成交易闭环，更利于信任、物流、评价和售后。

## 后台可以更新什么

后台地址：

```text
http://localhost:4173/admin.html
```

后台密码不写在网站文件里。线上后台密码需要在 Cloudflare Pages 的环境变量 `ADMIN_PASSWORD` 里设置。

后台目前可以维护：

- 产品名称
- 产品分类
- 颜色
- 价格
- 产品状态
- 产品描述
- Amazon 产品链接
- Amazon 按钮文案
- 博文标题
- 博文日期
- 博文摘要
- 博文正文

## Amazon 链接怎么填

产品还没上架 Amazon 时：

- `Amazon URL` 留空
- 前台显示：`Amazon Coming Soon`

产品已经上架 Amazon 后：

- `Amazon URL` 填 Amazon 商品链接
- `Amazon Button Text` 建议填：`View on Amazon`

示例：

```text
https://www.amazon.com/dp/XXXXXXXXXX
```

如果后期有 Amazon 品牌旗舰店，也可以增加入口：

```text
https://www.amazon.com/stores/品牌名
```

## 上线到 jhicashmere.com 的建议

你现在域名在腾讯云购买，已经托管到 Cloudflare。建议不再单独买服务器，先用：

- Cloudflare Pages：放前台网站
- Cloudflare Workers / Pages Functions：做后台接口
- Cloudflare D1：保存产品和博文数据
- Cloudflare Pages 环境变量：保存后台密码 `ADMIN_PASSWORD`

这样可以实现：

- `jhicashmere.com` 正式访问
- 后台在线登录
- 自己更新产品
- 自己更新博文
- 每个产品引导到 Amazon 下单
